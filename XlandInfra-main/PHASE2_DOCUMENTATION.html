MODULE 1: BILLING & PAYMENTS

Overview

The Billing & Payments module provides complete financial workflow management from invoice generation to payment collection, supporting multiple payment methods including online payment links.

Sidebar Navigation Structure

Billing & Payments │ ├── Generate Invoice ├── Invoices ├── Payments ├── Payment Link ├── Payment History └── Dashboard (Payments Overview) │ ├── Create Invoice (Other Requirements) │ └── Work Order Invoice (WO Submissions Only)

MODULE 2: SCHEDULING

Overview

The Scheduling module manages service requests from initial inquiry through on-site assessment to job completion, with calendar visualization and team assignment capabilities.

Sidebar Navigation Structure

Schedules │ ├── Requests ├── Calendar ├── Quotes ├── Jobs ├── Invoices (linked) └── Payments (linked) NOTE: Use "Customers" instead of "Clients"

Updated Sidebar Structure

Manager Dashboard │ ├── Dashboard ├── Properties ├── Vendors ├── Employees → Zones ├── Work Orders ├── Estimates │ ├── 📅 SCHEDULES (NEW) │ ├── Requests │ ├── Calendar │ ├── Quotes │ └── Jobs │ ├── 💰 BILLING & PAYMENTS (NEW) │ ├── Generate Invoice │ ├── Invoices │ ├── Payments │ ├── Payment Link │ ├── Payment History │ ├── Dashboard │ ├── Create Invoice │ └── Work Order Invoice │ └── Settings

Database Tables Required

Billing & Payments Tables

-- Invoices invoices ( id, invoice_number, property_id, estimate_id, customer_id, invoice_date, due_date, billing_period_start, billing_period_end, subtotal, discount, gst_amount, total_amount, paid_amount, balance_due, status (pending/partially_paid/paid/overdue), notes, created_by, created_at, updated_at ) -- Payments payments ( id, payment_number, invoice_id, amount, payment_date, payment_method (cash/bank_transfer/upi/payment_link), reference_number, received_by, notes, status, created_at ) -- Payment Links payment_links ( id, link_code, invoice_id, amount, expiry_date, status (generated/sent/expired/paid), sent_via (email/sms/both), sent_at, paid_at, created_at )

Scheduling Tables

-- Requests schedule_requests ( id, request_number, title, first_name, last_name, company_name, phone, email, lead_source, referrer_name, street1, street2, city, state, postal_code, country, service_category_id, service_subcategory_id, description, available_date, preferred_time (anytime/morning/afternoon/evening), has_pets, comments, images_json, status (unscheduled/scheduled/in_progress/completed/cancelled), created_by, created_at, updated_at ) -- On-site Assessments onsite_assessments ( id, request_id, instructions, start_date, end_date, start_time, end_time, schedule_later, anytime, checklists_json, notes, completion_percentage, created_at, updated_at ) -- Assessment Team assessment_team ( id, assessment_id, employee_id, assigned_at ) -- Jobs jobs ( id, request_id, job_number, status, scheduled_date, completed_date, actual_start_time, actual_end_time, completion_notes, created_at, updated_at )
